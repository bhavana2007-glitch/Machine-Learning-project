# Machine-Learning-project
Iris Flower Classification

Project Overview

This project focuses on classifying Iris flower species using Machine Learning algorithms. The dataset was loaded, explored, preprocessed, and used to train multiple classification models.

Dataset

- Iris Dataset (Scikit-learn)
- Features:
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width
- Target:
  - Species

Machine Learning Models Used

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Random Forest Classifier

Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score

Results

Best Model

Random Forest was selected as the best model due to its robustness and excellent performance.

Conclusion

All three machine learning models achieved perfect classification performance on the Iris dataset. The project demonstrates the effectiveness of machine learning techniques for flower species classification.
